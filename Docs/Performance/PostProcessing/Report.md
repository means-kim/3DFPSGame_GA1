# 포스트 프로세싱(색 보정·블룸·그레인) 리포트 (2026-11-02)

노을 조명 작업 이후 화면 마무리로 색 보정, 블룸, 필름 그레인을 순서대로 적용했다. 색이 확정되어야 블룸 임계값을 정할 수 있고, 그레인은 최종 마무리이므로 이 순서로 진행했다.

## 1. 색 보정 (`ColorGrading/`)
- URP 색 보정 모드: LDR → **HDR** (`PC_RPAsset`). ACES 톤매핑과 맞물려 밝은 하늘의 색이 덜 뭉개진다.
- **Color Curves**(Hue vs Hue): 노란색 영역만 주황 쪽으로 이동했다. 대기 두께를 낮추면서 노래진 하늘을 호박·주황 톤으로 되돌렸다.
- **Split Toning을 끄고 Shadows Midtones Highlights로 교체**: 그늘은 푸르게, 하이라이트는 따뜻하게 분리했다.
- Color Adjustments: 노출 0.35 → 0.2, 대비 5 → 12
- 후보 4개(현재 / HDR만 / HDR+색상 이동 / 전체) 비교: `candidates.png`

## 2. 블룸 (`Bloom/`)
- 장면 HDR 밝기 측정 결과
  - 태양: 화면의 0.6%만 밝기 3 초과
  - 창문: 최대 1.0이라 원래 임계값으로는 블룸이 걸리지 않음
  - 폭발: 화면의 23%가 0.9 초과해 바닥 전체가 번질 위험
- 적용 값: 임계값 0.9 → 1.0, 세기 0.5 → 1.0, 퍼짐 0.6 → 0.75
- **렌즈 먼지**: `Assets/09.Materials/PostProcessing/LensDirt.png`를 절차적으로 생성(흐린 얼룩, 마른 물방울 자국, 먼지 점, 시드 고정)하고 세기 5로 적용했다.
- 창문 발광 세기를 1.4 → 4로 올려 블룸이 걸리게 했다(`*_WindowLit.mat`).
- 결과는 은은한 편이다. 창문(F)에서 가장 잘 보이고, 렌즈 먼지는 태양이나 폭발을 정면으로 볼 때만 드러난다.

## 3. 필름 그레인 (`FilmGrain/`)
- Film Grain: Medium2, 세기 0.3, 응답 0.8
- 세기 1.0에서 하늘 이웃 픽셀 차이가 2.54 → 4.14로 늘어 적용되는 것을 확인했다. 0.3에서는 1.03 → 1.62.
- 정지 화면 원본 크기에서는 거의 구분되지 않는다. `zoom_sky_H.png`(하늘 4배 확대)에서 하늘 그라데이션의 가로 줄무늬(밴딩)가 고운 입자로 덮이는 것을 볼 수 있다.
