# 포인트 조명 · 그림자 거리 적용 리포트 (2026-11-02)

노을 조명 작업의 후속으로 따뜻한 포인트 조명 8개를 배치하고, 그림자 거리(Shadow Distance)를 50m에서 80m로 늘렸다. 화면과 Stats 창을 전/후로 비교했다.

## 변경 내역
- `GameScene.unity`: `PointLights` 아래에 Point Light 8개를 추가했다.
  - 위치: 전기함 4곳, 발전기 1곳, 좀비 스포너(교전 구역) 3곳.
  - 설정: 2700K, Intensity 25, Range 12, Realtime, **그림자 없음**.
  - URP는 물리 기반 감쇠를 쓰기 때문에 Intensity 3에서는 거의 보이지 않았다. 그래서 25로 올렸다.
  - `PointLight_ElectricBox_3`는 격납고 콜라이더 안에 묻혀 있어서 x로 +2.5m 옮겼다.
- `PC_RPAsset.asset`: Shadow Distance를 50에서 **80**으로 늘렸다. 캐스케이드는 4개, 분할 비율(0.12 / 0.29 / 0.54)은 그대로 두었다.

## 측정 방법
- 시점 A~D는 `../OptimizationReport.md`와 같은 위치와 회전을 쓴다. 화면 비교에는 시점 E(스포너 근처 교전 구역)를 추가했다.
- **Stats:** Play 모드에서 `Time.timeScale = 0`으로 멈추고, Main Camera의 `CameraFollow`/`CameraRotate`를 런타임에만 끈 뒤 고정 시점에 둔다.
  - Game 뷰 Stats를 켠 상태에서 Unity 창을 앞으로 가져와 화면 캡처한다.
  - Scene 뷰 카메라는 빈 공간으로 돌려 두었다가 캡처 후 원래 위치로 복원했다.
- **화면:** 에디터에서 오프스크린 카메라로 렌더링했다. 포스트 프로세싱은 포함하고, Player 레이어와 UI는 제외했다.
- Stats 값은 한 프레임 스냅샷이다. FPS와 CPU ms는 에디터 오버헤드 때문에 ±0.5ms 안팎으로 흔들리므로 참고용으로만 본다.

## 해석
1. **포인트 조명:** Batches와 SetPass에 의미 있는 변화가 없다. 렌더러가 Forward+여서 추가 라이트가 Draw Call을 늘리지 않고, 그림자도 꺼 두었기 때문이다. 화면에서는 교전 구역의 벽과 노면에 따뜻한 빛이 생긴다(시점 E).
2. **그림자 거리 50 → 80m:** 비용 증가의 대부분을 차지한다.
   - 모든 시점에서 Shadow casters가 늘었다(+6% ~ +118%).
   - 넓은 시야인 C에서 가장 크게 늘었고, Batches는 +58, Tris는 1.2M에서 2.3M으로 증가했다.
   - C의 삼각형 증가는 카타나(LOD0 500k tris) 등 고폴리 메시가 더 많은 캐스케이드의 그림자 패스에 포함된 영향으로 추정된다(미검증).
   - 화면 차이는 크지 않다. 50~80m 구간의 건물에도 그림자가 생기지만, Fog(30~220m)와 낮은 해 때문에 고정 시점 캡처에서는 미묘하게만 보인다. 이동 중 그림자가 갑자기 생기는 경계가 멀어지는 것이 주된 효과다.
3. **프레임 시간:** 모든 시점에서 CPU main 차이가 ±0.1ms라 측정 오차 안이다. 에디터 기준으로는 체감되는 부담이 없다.

## 남은 과제
- C처럼 넓은 시야에서 그림자 비용이 커지므로, 저사양 품질 레벨(Mobile_RPAsset 등)은 거리를 50 이하로 유지하는 것이 좋다.
- `OptimizationReport.md`에서 지적한 카타나 고폴리 문제가 그림자 거리 확장으로 더 커졌다. 카타나의 Cast Shadows를 끄거나 메시를 데시메이션하는 방안을 검토한다.
- 시점 B·C의 맵 가장자리에서 스카이박스 지면색(검붉은색)이 넓게 보인다. 맵 밖 바닥 메시나 Fog 거리 조정으로 가리는 것을 고려한다.
