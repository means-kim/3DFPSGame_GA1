# 격납고 창문 발광(Emission) 적용 리포트 (2026-11-02)

해질녘 분위기를 살리려고 격납고 창문에 실내등이 켜진 것처럼 발광을 넣었다. 외부 에셋(`RPG_FPS_game_assets_industrial`)은 수정하지 않았다. 대신 우리 폴더에 발광 맵과 머티리얼 복제본을 만들고, 씬의 렌더러만 교체했다.

## 조사 결과
- 맵 에셋 머티리얼 27종은 모두 `_EMISSION` 키워드만 켜져 있고 발광 색이 검정(0,0,0)이었다. 실제로 빛나는 것은 좀비 눈뿐이었다.
- 격납고 메시는 서브메시 1개와 아틀라스 텍스처 1장으로 되어 있다. 창문만 따로 머티리얼을 줄 수 없어서 **아틀라스에서 창문 영역을 찾아 발광 마스크를 만드는 방식**을 택했다.
- 창문이 있는 아틀라스와 영역:
  - **Hangar_v4** (씬에 10채): 가로 창문 띠. 어두운 유리와 흰 창틀이라 Otsu 임계값으로 유리만 자동 분리했다. 18칸.
  - **Hangar_v3** (3채): 상단 격자창. 유리에 반사 무늬가 섞여 자동 분리가 얼룩져서 칸 좌표를 직접 지정했다. 12칸.
  - **Hangar_v2** (9채, outbuilding 포함): 유리블록 패널(자동 분리), 셔터 문 타원 창 2개(타원으로 채움), 상단 패널 10칸(좌표 지정, 환풍기 칸은 제외). 24칸.
  - Hangar_v1: 창문 없음.

## 변경 내역
- `Assets/09.Materials/WindowEmission/`
  - `Hangar_v2/v3/v4_Emission.png`: 발광 맵. 원본 아틀라스와 같은 해상도이고 창문 외에는 검정이다.
    - 칸마다 약 70%만 켜고, 밝기는 0.6~1.0 사이 무작위로 준다.
    - 색은 주로 따뜻한 백열등(1, 0.62, 0.3)이고 약 12%는 차가운 형광등(0.75, 0.85, 0.95)이다.
    - 칸 가장자리로 갈수록 어둡게 해서 실내 깊이감을 줬다. 유리 텍스처 무늬도 일부 반영했다.
    - 생성 시드를 고정(20261102)해서 다시 만들어도 같은 결과가 나온다.
  - `Hangar_v2/v3/v4_WindowLit.mat`: 원본 머티리얼(Simple Lit) 복제본이다. 발광 맵을 연결하고 `_EmissionColor`를 흰색 × 1.4(HDR)로 두었다.
- `GameScene.unity`: 격납고 렌더러 23개의 머티리얼을 `*_WindowLit`으로 교체했다(프리팹 인스턴스 오버라이드).

### 작업 중 발견한 주의점
- 처음 만든 머티리얼은 `globalIlluminationFlags = None`이었는데, 다시 로드할 때마다 URP 머티리얼 검증이 `_EMISSION` 키워드를 꺼 버렸다. 디스크(.mat)에는 키워드가 남아 있어서 원인을 찾기 어려웠다.
- 원본과 같은 **`RealtimeEmissive`(m_LightmapFlags: 1)** 로 바꾸자 해결되었다. 스크립트로 발광 머티리얼을 만들 때는 이 플래그를 함께 지정해야 한다.

## 측정 방법
`../PointLight_ShadowDistance/Report.md`와 같다. 시점 A~D에 창문이 잘 보이는 시점 F(Hangar_v4), G(Hangar_v2)를 추가했다.
- **Stats:** Play 모드, timeScale 0, 고정 시점, Game 뷰 Stats 화면 캡처(A~D, F).
  - 시점 A의 "작업 전" 캡처는 첫 시도 때 Unity 창이 앞으로 오지 않아 실패했다.
  - 그래서 Play 모드에서 런타임에만 원본 머티리얼로 되돌려 다시 찍었다.
- **화면:** 에디터 오프스크린 카메라(포스트 프로세싱 포함, Player 레이어와 UI 제외)로 A~D, F, G를 캡처했다.

## 해석
1. **렌더링 비용 변화 없음.**
   - SetPass와 Shadow casters는 모든 시점에서 그대로다.
   - Batches와 Tris는 ±5 / ±3k 안에서 흔들렸는데, 한 프레임 스냅샷이라 생기는 오차다.
   - 머티리얼을 교체만 했고 셰이더(Simple Lit)와 변형(`_EMISSION`)은 원본과 같다. 원본도 `_EMISSION`이 켜져 있었으므로 셰이더 변형이 새로 늘지 않는다.
2. **CPU main**은 ±2ms로 흔들렸다. 방향이 일정하지 않아 에디터 오차로 본다. A의 11.6ms는 재캡처 직전 Play 모드 진입 직후의 부하가 섞인 값이다.
3. **메모리:** 발광 맵 3장이 추가됐다.
   - 2048² DXT1 2장, 1024² DXT1 1장으로 밉맵 포함 약 6MB다.
   - 대부분이 검정이므로, 필요하면 Max Size를 1024로 낮춰 1/4로 줄일 수 있다.
4. **화면(F, G, D):**
   - 창문 띠에 따뜻한 불빛이 켜지고 일부는 꺼져 있어 사람이 있는 건물 같은 느낌이 난다.
   - Bloom(threshold 0.9)에 걸려 은은하게 번진다.
   - 전경(D)에서도 건물 옆면의 창문 띠가 점처럼 보여 해질녘 분위기를 더한다.

## 남은 과제 / 조정 포인트
- 같은 격납고 모델은 모두 같은 창 패턴으로 켜진다. 건물마다 다르게 하려면 머티리얼 변형을 2~3개 만들어 섞거나 MaterialPropertyBlock으로 세기를 다르게 줘야 한다.
- 밝기는 `*_WindowLit.mat`의 `_EmissionColor` 세기(현재 1.4)로 한 번에 조절할 수 있다.
- 칸 좌표와 켜짐 확률은 생성 스크립트 값이다. 바꾸려면 스크립트를 수정해 맵을 다시 만들어야 한다.
